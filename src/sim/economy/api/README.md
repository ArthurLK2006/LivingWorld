Porta de entrada do módulo `economy` (arquitetura 11.1): `EconomyModule` (consultas `peek_*` e comandos `request_*`), `EconomyReplies` (as cópias que a porta devolve) e `EconomyCodes` (os códigos de erro). O contrato (`docs/modules/economy.md`, seção 10) lista a API planejada; cada tarefa acrescenta a sua parte. O `npc` só pode citar classes desta pasta, e a `economy` nunca cita o `npc` (`tools/check_architecture`, regra E).
