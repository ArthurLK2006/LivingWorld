Porta de entrada do módulo `economy` (arquitetura 11.1): `EconomyModule` (consultas `peek_*` e comandos `request_*`), `EconomyReplies` (as cópias que a porta devolve), `EconomyCodes` (os códigos de erro) e as classes dos eventos que OUTROS módulos ouvem (hoje `WagesPaid`, que o `npc` ouve; os demais eventos da economia ficam em `events/` até alguém de fora precisar deles). O contrato (`docs/modules/economy.md`, seção 10) lista a API planejada; cada tarefa acrescenta a sua parte. O `npc` só pode citar classes desta pasta, e a `economy` nunca cita o `npc` (`tools/check_architecture`, regra E).
