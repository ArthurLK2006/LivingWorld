# Experimento descartável de terceira pessoa

Abra `third_person.tscn` no editor Godot e execute a cena atual com F6. Use W/A/S/D para andar, mouse para olhar, espaço para pular e Esc para liberar o mouse; clique na janela para capturá-lo novamente. Este experimento é isolado da simulação e não conclui as tarefas LW-045 ou LW-046.
